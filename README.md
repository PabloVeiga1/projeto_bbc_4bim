# 🎓 Projeto Final de Banco de Dados — 4º Bimestre

## 📌 Tema: Gestão de Eventos Acadêmicos

O projeto tem como objetivo desenvolver um sistema de **Gestão de Eventos Acadêmicos**, facilitando a organização e o gerenciamento de cadastros relacionados a eventos no ambiente educacional.
