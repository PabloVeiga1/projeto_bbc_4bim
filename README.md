# 🎓 Projeto Final de Banco de Dados — 4º Bimestre

## 📌 Tema: Gestão de Eventos Acadêmicos

## 🎯 Objetivo do Projeto

Desenvolver uma aplicação funcional para a gestão de eventos acadêmicos, permitindo organizar atividades, gerenciar palestrantes e registrar participantes de maneira prática e eficiente.

---

## ✅ Requisitos de Desenvolvimento

Cada integrante deverá garantir que seu cadastro contenha todas as seguintes etapas:

1. Criação da tabela correspondente no banco de dados.
2. Implementação das classes necessárias.
3. Desenvolvimento das rotas para as operações do cadastro.
4. Criação da tela de listagem dos registros.
5. Criação da tela de cadastro de novos registros.

> **Importante:** cada cadastro deverá estar completo e funcionando corretamente, contemplando todas as etapas de desenvolvimento.
