# 🎓 Projeto Final de Banco de Dados — 4º Bimestre

## 📌 Tema: Gestão de Eventos Acadêmicos

O projeto tem como objetivo desenvolver um sistema de **Gestão de Eventos Acadêmicos**, facilitando a organização, o gerenciamento e o controle dos cadastros relacionados aos eventos no ambiente educacional.

## 🛠️ Divisão de Responsabilidades

Cada integrante será responsável pelo desenvolvimento de **pelo menos um cadastro completo** entre os cadastros principais do tema.

Cada cadastro deverá contemplar todas as seguintes etapas:

- 🗄️ **Tabela no banco de dados:** criação e estruturação da tabela.
- 💻 **Classes:** implementação das classes necessárias.
- 🔀 **Rotas:** desenvolvimento das rotas para as funcionalidades do cadastro.
- 📋 **Tela de listagem:** exibição dos registros cadastrados.
- 📝 **Tela de cadastro:** formulário para inserir novos registros.

## 🎯 Objetivo do Projeto

Desenvolver uma aplicação funcional para a gestão de eventos acadêmicos, garantindo que cada integrante participe do desenvolvimento completo de pelo menos um dos cadastros principais do sistema.

---

## ✅ Requisitos de Desenvolvimento

Cada integrante deverá entregar seu cadastro contemplando:

1. Criação da tabela correspondente no banco de dados.
2. Implementação das classes relacionadas.
3. Desenvolvimento das rotas necessárias.
4. Criação da tela de listagem dos registros.
5. Criação da tela de cadastro de novos registros.

**Importante:** o cadastro só será considerado completo quando todas as etapas estiverem implementadas e funcionando corretamente.
